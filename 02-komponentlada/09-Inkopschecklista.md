# Steg 1 – Inköpschecklista

## Rekommenderat arbetssätt

Köp inte allt direkt om målet är att testa bokidén. Börja med Baslådan, skapa de första experimenten och komplettera därefter.

---

# Checklista före inköp

## Plattform

- [ ] ESP32 DevKit valt som standardkort
- [ ] USB-kabeln är datakabel, inte bara laddkabel
- [ ] Kortet passar på breadboard eller kan kopplas med jumperkablar
- [ ] Arduino IDE-stöd finns

## Breadboard och kablage

- [ ] Minst ett stort breadboard
- [ ] Tillräckligt många hane-hane-kablar
- [ ] Hane-hona-kablar för moduler
- [ ] Gärna flera färger för plus, minus och signal

# Rekommenderad inköpsstrategi

## Första inköp

Köp Baslådan.

Om budget finns, lägg till:

- M01 SG90 servo
- L03 NeoPixel-ring
- S05 DHT22
- K03 TTP229 touch-sensor

Dessa ger snabbt många roliga experiment.

## Vänta med

- RFID
- MicroSD
- RTC
- stegmotor

De är användbara men bör inte styra bokens första experiment.
