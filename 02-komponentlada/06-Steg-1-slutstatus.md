# Steg 1 – Slutstatus och kvarvarande beslut

## Sammanfattning

Steg 1 handlar om att definiera bokens experimentplattform och standardiserade komponentlåda. Detta är nu i stort sett färdigt.

## Klara delar

| Del | Status |
|---|---|
| Val av plattform | Klart |
| Rekommenderad styrenhet | ESP32 DevKit |
| Komponentnivåer | Klart |
| Baslåda | Klart |
| Pluslåda | Klart |
| Makerlåda | Klart |
| Komponent-ID | Klart |
| Nyttopoäng | Klart |
| Komponentpass | Klart |
| Mall för experimentens komponentruta | Klart |
| Designprinciper | Klart |
| Kostnadsöversikt | Kompletterad i v5 |
| Säkerhets- och kompatibilitetsnoteringar | Kompletterad i v5 |
| Inköpschecklista | Kompletterad i v5 |

## Beslut

Boken baseras på:

- ESP32 DevKit
- Arduino IDE
- breadboard
- 3,3V-logik
- fasta komponent-ID:n
- tre inköpsnivåer: Baslåda, Pluslåda och Makerlåda

## Rekommendation

Steg 1 kan betraktas som **klart nog för att gå vidare till Steg 2 – Färdighetskartan**.

Komponentlådan kan senare justeras efter att Experimentbanken och Komponentanalysen visar om vissa komponenter används för lite eller bör bytas ut.
