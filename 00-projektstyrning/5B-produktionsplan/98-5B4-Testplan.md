# 5B.4 – Testplan

## Testnivåer

| Nivå | Syfte |
|---|---|
| Kodtest | Kontrollera att koden kompilerar och kör |
| Breadboardtest | Kontrollera att kopplingen fungerar praktiskt |
| Vuxentest | En vuxen bygger enligt instruktionen |
| Barntest | Barn testar med vuxenstöd |
| Layouttest | Kontrollera att text, kod och bild hänger ihop |

## Testprotokoll per experiment

| Fält | Beskrivning |
|---|---|
| Experiment-ID | E001–E120 |
| Testdatum | När testet gjordes |
| Testare | Vuxen/barn/AI-stöd |
| Fungerade direkt? | Ja/Nej |
| Problem | Vad hände? |
| Åtgärd | Vad ändrades? |
| Ny teststatus | Ej testad/Testad/Problem/Klar |

## Minimikrav före publicering

- Kodtestad.
- Breadboardtestad.
- Teknisk granskning klar.
- Pedagogisk granskning klar.
