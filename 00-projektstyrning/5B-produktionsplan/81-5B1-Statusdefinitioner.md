# 5B.1 – Statusdefinitioner

## Textstatus

| Status | Betydelse |
|---|---|
| Ej påbörjad | Ingen text finns |
| Utkast | Första manus finns |
| Reviderad | Text har förbättrats |
| Klar | Text är redo för layout |

## Kodstatus

| Status | Betydelse |
|---|---|
| Ej påbörjad | Ingen kod skriven |
| Utkast | Kod finns men ej testad |
| Kodtestad | Koden har körts |
| Klar | Kod är redo för bok |

## Breadboardtest

| Status | Betydelse |
|---|---|
| Ej testad | Koppling ej praktiskt verifierad |
| Testad av vuxen | Testad av tekniskt kunnig vuxen |
| Testad med barn | Testad pedagogiskt med barn |
| Problem | Kräver korrigering |

## Granskning

| Status | Betydelse |
|---|---|
| Ej granskad | Ingen kontroll gjord |
| Teknisk granskning klar | Koppling/kod/säkerhet kontrollerad |
| Pedagogisk granskning klar | Nivå, språk och progression kontrollerad |
| Komplett granskad | Båda granskningar klara |
