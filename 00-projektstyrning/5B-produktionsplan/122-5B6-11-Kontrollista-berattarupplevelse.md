# 5B.6.11 – Kontrollista för berättarupplevelsen

## Syfte

Denna kontrollista används innan ett experiment markeras som 5B.6-reviderat, guldstandard-kandidat eller färdigt.

Den är avsedd att användas tillsammans med:

- experimentmallen,
- produktionsmatrisen,
- teknisk granskning,
- pedagogisk granskning,
- illustrationsplanen,
- fysisk breadboardtest.

---

| Kontrollpunkt | Ja/Nej | Kommentar |
|---|---|---|
| Inledningen väcker nyfikenhet |  |  |
| Experimentet har ett tydligt uppdrag |  |  |
| Barnet förstår varför experimentet är värt att göra |  |  |
| Öppningen känns som en upptäckarbok, inte manual |  |  |
| Slutet pekar mot nästa upptäckt |  |  |

| Kontrollpunkt | Ja/Nej | Kommentar |
|---|---|---|
| En huvudidé dominerar experimentet |  |  |

| Förklaringen kommer efter upplevelsen när det är möjligt |  |  |

# Statusbedömning

Använd följande nivåer:

| Status | Betydelse |
|---|---|
| Utkast | Idé och grundtext finns |
| 5B.6-reviderad | Texten följer designbibeln men är inte färdigtestad |
| Guldstandard-kandidat | Stark referenstext, men fysisk/pedagogisk slutgranskning kan kvarstå |
| Färdig | Fysiskt testad, tekniskt granskad, pedagogiskt testläst och layoutklar |

---

# Beslut

Denna checklista ska användas för E001–E002 innan nästa produktionsblock fortsätter.

# v83-tillägg – Kontroll av experimentprogression

Lägg till följande kontroll före produktion av nytt huvudexperiment:

| Fråga | Svar |
|---|---|
| Tillför experimentet något nytt i progressionen? |  |
| Är det mer än en variant av samma koppling/kodidé? |  |
| Skulle idén fungera bättre som Testa/Utforska/Utmaning? |  |
| Om experimentet ligger sist i kapitlet: fungerar det som syntes? |  |
| Behöver tidigare eller nästa experiment justeras om ordningen ändras? |  |

Om svaret antyder att experimentet är en variant ska det inte automatiskt produceras som eget huvudexperiment.
