# 5B.6.3 – Emotionell progression

## Syfte

Detta dokument beskriver vilka känslor boken ska bygga genom kapitlen. Det är viktigt eftersom barn inte fortsätter genom 120 experiment enbart för att innehållet är logiskt. De fortsätter för att de känner:

- jag klarar det,
- det är roligt,
- jag vill se vad som händer sen,
- jag kan bygga något eget.

---

# Huvudresa

Bokens emotionella resa:

```text
Det blinkar!
  ↓
Jag styr!
  ↓
Den reagerar!
  ↓
Jag kan mäta världen!
  ↓
Jag kan bygga prylar!
  ↓
Jag kan skapa själv!
```

---

# Kapitelvisa känslomål

| Kapitel | Känsla barnet ska få |
|---:|---|
| 1 | Jag fick den att leva |
| 2 | Jag kan skapa ljus och färg |
| 3 | Jag kan styra med knappar |
| 4 | Jag kan bygga spel och ljud |
| 5 | Elektroniken kan känna av världen |
| 6 | Jag kan bygga larm och hemliga system |
| 7 | Jag kan undersöka miljön runt mig |
| 8 | Mina prylar kan visa information |
| 9 | Jag kan skapa ljusanimationer och spel |
| 10 | Mina prylar kan röra sig |
| 11 | Jag kan styra motorer och robotar |
| 12 | Jag kan bygga nycklar och fjärrkontroller |
| 13 | Mina prylar kan minnas tid, data och nät |
| 14 | Jag kan hitta på en egen uppfinning |

---

# Självförtroendekurvan

Barnet ska inte känna att varje kapitel är svårare på ett tungt sätt. Det ska kännas som att verktygslådan växer.

Fel känsla:

> Nu blev det mycket svårare.

Rätt känsla:

> Nu kan jag använda det jag redan kan till något nytt.

---

# Återkommande emotionella ankare

## Stolthet

Efter varje kapitelprojekt ska barnet kunna visa något för någon annan.

## Nyfikenhet

“Jag undrar...” ska skapa frågor som senare får svar.

## Trygghet

Felsökning ska vara normalt och förväntat.

## Ägarskap

Barnet ska ofta få välja färg, rytm, gränsvärde, ljud eller regel.

## Skaparglädje

Kapitel 14 ska kännas som en naturlig fortsättning, inte som ett prov.

---

# Risker och motåtgärder

| Risk | Känsla | Motåtgärd |
|---|---|---|
| För mycket teori | trötthet | bygg först, förklara sen |
| För mycket felsökning | misslyckande | gör felsökning till mysterium |
| För stora projekt | överväldigande | minsta fungerande version |
| För lite valfrihet | passivitet | lägg in Utforska/Utmaning |
| För mycket vuxenstyrning | “jag kan inte själv” | vuxen är mentor, inte lösningsägare |

---

# Emotionella mål för E001–E002

## E001

Barnet ska känna:

> Den blinkar för att jag sa åt den att blinka.

## E002

Barnet ska känna:

> Jag kan ändra hur den beter sig.

Dessa två känslor är grunden för resten av boken.

---

# Beslut

Varje experiment ska inte bara ha lärandemål utan också ett implicit känslomål. Det behöver inte alltid skrivas ut i boken, men det ska styra skrivandet.
