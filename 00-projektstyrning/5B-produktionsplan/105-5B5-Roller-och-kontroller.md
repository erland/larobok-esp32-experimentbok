# 5B.5 – Roller och kontroller

## Roller

| Roll | Ansvar |
|---|---|
| Författare | skriver experimenttext |
| Teknisk granskare | kontrollerar koppling och kod |
| Pedagogisk granskare | kontrollerar barnnivå och rytm |
| Testbyggare | bygger enligt instruktionen |
| Illustratör | skapar bilder |
| Layoutansvarig | sätter experimentet i bokformat |

Samma person kan ha flera roller, men kontrollerna ska ändå göras separat.

## Kontrollpunkter

| Punkt | Fråga |
|---|---|
| Textutkast | Är experimentet begripligt? |
| Kodtest | Fungerar koden? |
| Breadboardtest | Går kopplingen att bygga? |
| Teknisk granskning | Är det säkert och korrekt? |
| Pedagogisk granskning | Passar det barn 7–12? |
| Layout | Hänger text, bild och kod ihop? |
