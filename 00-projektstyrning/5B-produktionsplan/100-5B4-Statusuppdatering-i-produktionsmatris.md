# 5B.4 – Statusuppdatering i produktionsmatris

## Syfte

Kvalitetssäkring ska alltid speglas i produktionsmatrisen.

## Fält som ska uppdateras

| Fält | När uppdateras det? |
|---|---|
| Textstatus | när experimenttext skrivs/revideras |
| Kodstatus | när kod skrivs/testas |
| Breadboardtest | när fysisk koppling testas |
| Illustrationsstatus | när bild planeras/skapas |
| Teknisk granskning | efter teknisk kontroll |
| Pedagogisk granskning | efter pedagogisk kontroll |
| Layoutstatus | efter layoutarbete |
| Slutstatus | när allt är klart |

## Rekommenderade slutstatusar

- Planerad
- Pågår
- Blockerad
- Klar för granskning
- Revideras
- Färdig
- Flyttad till bonus
- Flyttad till webbmaterial
