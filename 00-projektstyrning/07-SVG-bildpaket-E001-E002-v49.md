# v49 – Första kompletta SVG-bildpaket för E001–E002

## Syfte

Detta paket innehåller första kompletta SVG-bildpaketet för E001 och E002.

Bilderna är skapade som kontrollerbara SVG-underlag, inte som fria AI-genererade kopplingsbilder.

## E001-bilder

| Fil | Syfte |
|---|---|
| `E001-A-dagens-delar.svg` | Visar komponenterna innan koppling |
| `E001-B-led-polaritet.svg` | Visar långt/kort LED-ben |
| `E001-C-kopplingsoversikt.svg` | Visar kopplingsvägen GPIO 23 → LED → motstånd → GND |
| `E001-C-connection-map.svg` | Alias/kopia av kopplingsöversikten för bakåtkompatibilitet |
| `E001-D-vanliga-ledtradar.svg` | Visar vanliga felsökningsledtrådar |
| `E001-E-forsta-blinket.svg` | Visar PÅ/AV och första blinket |

## E002-bilder

| Fil | Syfte |
|---|---|
| `E002-A-samma-koppling-ny-kod.svg` | Visar idén samma koppling, ny kod |
| `E002-B-kopplingskontroll.svg` | Visar snabb kontroll av kopplingen |
| `E002-C-rytm-tidslinje.svg` | Visar blink-blink-paus som tidslinje |
| `E002-C-rhythm-timeline.svg` | Alias/kopia för bakåtkompatibilitet |
| `E002-D-rytmjamforelse.svg` | Visar skillnad mellan kort och lång paus |
| `E002-E-vanliga-ledtradar.svg` | Visar felsökningsledtrådar för E002 |

## Viktig begränsning

Dessa bilder är första bokillustrationsunderlag. De är inte slutligt tekniskt godkända förrän:

1. de jämförts mot `circuit.yaml`,
2. Wokwi-/breadboardbild kontrollerats,
3. fysisk breadboardtest genomförts,
4. bildtexter matchats mot slutligt manus.

## Nästa steg

Skapa en PDF-preview för E001–E002 där dessa SVG-bilder faktiskt placeras in i texten.
