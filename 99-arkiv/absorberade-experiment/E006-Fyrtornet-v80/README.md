# E006 Fyrtornet – arkiverat i v81

E006 skapades som ett separat experiment i v79 och bildputsades i v80.

I v81 beslutades att E006 ligger för nära E002 för att bära ett eget experiment i Kapitel 1.

Det bästa innehållet från E006 har därför bakats in i E002 som en fyrtornsutmaning:

- manusidé: lugn fyrtornsrytm,
- kodidé: långt blink, kort paus, kort blink, lång paus,
- bildidé: fyrtornssekvens,
- pedagogisk idé: pausen är också en del av signalen.

De gamla E006-filerna ligger kvar här enbart som historik.
