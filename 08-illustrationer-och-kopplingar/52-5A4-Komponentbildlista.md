# 5A.4 – Komponentbildlista

## Syfte

Varje komponent som återkommer i boken bör ha en standardiserad komponentbild eller ikon. Detta gör att barnet känner igen komponenterna och minskar behovet av att förklara samma sak flera gånger.

---

| ID | Komponent | Bildbehov | Kommentar |
|---|---|---|---|
| E01 | ESP32 DevKit | komponentbild + pinöversikt | mycket viktig |
| B01 | Breadboard | komponentbild + radförklaring | mycket viktig |
| B02/B03 | Jumperkablar | komponentbild | färgkodning |
| R01 | Motstånd | komponentbild + färgkod enkel | återkommer ofta |
| L01 | LED | komponentbild + polaritet | kritisk |
| L02 | RGB-LED | komponentbild + pinout | kritisk |
| K01 | Tryckknapp | komponentbild + breadboardplacering | kritisk |
| K02 | Potentiometer | komponentbild + ben | analog input |
| A01 | Passiv buzzer | komponentbild | skilj från aktiv buzzer |
| S01 | LDR | komponentbild | analog sensor |
