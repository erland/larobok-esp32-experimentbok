# 5A.4 – Illustrationskö och prioritering

## Syfte

Alla bilder behöver inte produceras samtidigt. Detta dokument föreslår en ordning som ger mest nytta tidigt i produktionen.

---

# Prioritet 1 – Kritiska grundbilder

Dessa bör produceras först eftersom de påverkar hela boken:

| Bild | Varför prioriterad |
|---|---|
| ESP32-pinöversikt | används i många experiment |
| Breadboardrad-förklaring | minskar många nybörjarfel |
| LED-polaritet | kritisk från första kapitlet |
| Motstånd + LED | första standardkoppling |
| Knappplacering | vanligt fel |
| INPUT_PULLUP-bild | vanligt missförstånd |
| Buzzer-koppling | start för ljud/spel |
| RGB-LED pinout | vanligt fel |
| LDR-spänningsdelare | första analogsensor |
| HC-SR04 säkerhetsbild | viktig ESP32-kompatibilitet |

# Prioritet 3 – Fördjupnings- och bonusbilder

Dessa kan vänta tills bonusprojektens omfattning är låst:

- touchpiano,
- Mini-Snake,
- stegmotor/karusell,
- fjärrstyrd servo,
- WiFi-webbsida,
- escape-room-låda.

---

# Rekommenderad produktionsordning

1. Skapa gemensam bildstil.
2. Skapa grundbilder för Kapitel 1–4.
3. Skapa breadboardmallar för standardkopplingar.
4. Skapa komponentbilder för Baslådan.
5. Skapa projektbilder för Kapitel 1–7.
6. Skapa Pluslådans komponentbilder.
7. Skapa projektbilder för Kapitel 8–10.
8. Skapa Makerbilder för Kapitel 11–14.

---

# Produktionsstatusfält

När illustrationsarbetet börjar bör varje bild få status:

| Status | Betydelse |
|---|---|
| Planerad | finns i illustrationsplanen |
| Skiss | grov layout finns |
| Teknisk kontroll | koppling kontrolleras |
| Slutbild | färdig grafisk version |
| Införd | införd i manus |
